# Third-party code

`site/vendor/` contains two libraries, unmodified, under their own licences.
Those licences govern those files — this project's CC BY-NC terms do not apply
to them and cannot restrict them.

| File | Project | Version | Licence |
|---|---|---|---|
| `pdf.min.js`, `pdf.worker.min.js` | [pdf.js](https://github.com/mozilla/pdf.js) — Mozilla | 3.11.174 | Apache License 2.0 |
| `pdf-lib.min.js` | [pdf-lib](https://github.com/Hopding/pdf-lib) | 1.17.1 | MIT |

They are committed rather than fetched from a CDN so the page keeps working
with no network. If you fork this, keep this file with them.
